# Barzi Configuration

This project includes opinionated terminal configurations from barzi-dawg, AKA Amit Barzilai, AKA [Yung Fundamental](https://github.com/yungFundamental).

## Installation
Installation is done by pulling the repository to your directory, and adding the following line to your `.bashrc`:

```bash
source ~/barzi-config/bash/rc
```

Currently, installation isn't the most comfortable. This is due to the small expected scale of this project.
If you find yourself wishing there was an easier way to install this on your local machine, feel free to open an issue or PR.
